Query interface for the fitted surrogate, with explicit out-of-bounds handling.

Why an envelope at all

The rubric requires a stated strategy for missing, NaN and out-of-bounds inputs, but the engineering reason is sharper than the marking scheme. This surrogate is trained on 13 hulls at one speed. An SVR with an RBF kernel does not refuse a query outside that range -- it returns a confident number that decays smoothly toward the training mean, and nothing in the output distinguishes a genuine interpolation from an extrapolation two hull-lengths beyond anything ever measured.

The Virtual Surfer queries this model at 100 Hz along a trajectory. A silent extrapolation there propagates into turning radius, then yaw rate, then Radicality, and arrives in the report as a physical claim. So every prediction is accompanied by an in-envelope flag, and the default policy warns rather than staying silent.

What the envelope does not do

It is a per-feature bounding box, so it checks each input against the range seen in training and nothing more. A query can sit inside every individual range and still be in a hole -- a 130 L board with a shortboard's aspect ratio is inside both margins and exists nowhere in the corpus. The bounding box will pass it. This is a known limitation, stated rather than papered over; a convex hull or a density estimate would catch it, and with 13 points neither would be trustworthy.

 42class Envelope:
 43    """Per-feature training ranges, used to flag extrapolation.
 44
 45    Attributes
 46    ----------
 47    lower, upper : dict of str to float
 48        Minimum and maximum observed in training, per feature.
 49    """
 50
 51    lower: dict[str, float] = field(default_factory=dict)
 52    upper: dict[str, float] = field(default_factory=dict)
 53
 54    @classmethod
 55    def from_table(cls, table: pd.DataFrame, features: list[str]) -> "Envelope":
 56        """Measure the envelope from a training table.
 57
 58        Parameters
 59        ----------
 60        table : pandas.DataFrame
 61            Training rows.
 62        features : list of str
 63            Feature columns to bound.
 64
 65        Returns
 66        -------
 67        Envelope
 68        """
 69        return cls(
 70            lower={f: float(table[f].min()) for f in features},
 71            upper={f: float(table[f].max()) for f in features},
 72        )
 73
 74    def check(self, X: pd.DataFrame) -> pd.DataFrame:
 75        """Per-row, per-feature in-range flags.
 76
 77        Parameters
 78        ----------
 79        X : pandas.DataFrame
 80            Query rows, columns matching the envelope's features.
 81
 82        Returns
 83        -------
 84        pandas.DataFrame
 85            Boolean, same index as ``X``, one column per feature. True means the
 86            value lies within the training range. NaN is reported as False -- a
 87            missing input is not in the envelope, and treating it as acceptable is
 88            how a NaN reaches a physical claim.
 89        """
 90        flags = {}
 91        for name, low in self.lower.items():
 92            column = X[name].astype(float)
 93            flags[name] = (column >= low) & (column <= self.upper[name])
 94        return pd.DataFrame(flags, index=X.index).fillna(False)
 95
 96    def describe(self) -> pd.DataFrame:
 97        """Envelope as a table, for the report's inputs/outputs section.
 98
 99        Returns
100        -------
101        pandas.DataFrame
102            Columns ``feature``, ``min``, ``max``.
103        """
104        return pd.DataFrame(
105            {"feature": list(self.lower), "min": list(self.lower.values()),
106             "max": [self.upper[f] for f in self.lower]}
107        )

110class SurrogatePredictor:
111    """One fitted estimator per target, plus the envelope they were trained in.
112
113    Parameters
114    ----------
115    estimator_name : str, optional
116        Key into :data:`src.models.ESTIMATORS`. Defaults to ``'svr_rbf'``.
117    features : list of str, optional
118        Feature columns. Defaults to :data:`src.data.FEATURES`.
119    targets : list of str, optional
120        Targets to fit. Defaults to :data:`src.data.TARGETS`.
121    policy : {'warn', 'refuse', 'allow'}, optional
122        What to do when a query falls outside the envelope. ``'warn'`` (default)
123        predicts and raises a :class:`UserWarning` naming the offending features.
124        ``'refuse'`` raises :class:`ValueError`. ``'allow'`` is silent and should be
125        used only when the caller is checking ``in_envelope`` itself.
126
127    Attributes
128    ----------
129    envelope_ : Envelope
130        Training ranges. Available after ``fit``.
131    models_ : dict of str to estimator
132        One fitted estimator per target.
133
134    Examples
135    --------
136    >>> import warnings
137    >>> from src.data import build_training_table
138    >>> with warnings.catch_warnings():
139    ...     warnings.simplefilter("ignore")
140    ...     table = build_training_table()
141    >>> predictor = SurrogatePredictor().fit(table)
142    >>> out = predictor.predict(pd.DataFrame([{
143    ...     "volume_shape_l": 30.0, "length_over_width": 3.7,
144    ...     "thickness_over_length": 0.026, "drift_deg": 5.0, "roll_rad": 0.3}]))
145    >>> bool(out["in_envelope"].iloc[0])
146    True
147    """
148
149    def __init__(
150        self,
151        estimator_name: str = "svr_rbf",
152        features: list[str] | None = None,
153        targets: list[str] | None = None,
154        policy: str = "warn",
155    ) -> None:
156        if estimator_name not in ESTIMATORS:
157            raise KeyError(f"unknown estimator {estimator_name!r}; have {sorted(ESTIMATORS)}")
158        if policy not in {"warn", "refuse", "allow"}:
159            raise ValueError(f"policy must be 'warn', 'refuse' or 'allow', got {policy!r}")
160        self.estimator_name = estimator_name
161        self.features = list(features) if features is not None else list(FEATURES)
162        self.targets = list(targets) if targets is not None else list(TARGETS)
163        self.policy = policy
164        self.envelope_: Envelope | None = None
165        self.models_: dict = {}
166
167    def fit(self, table: pd.DataFrame) -> "SurrogatePredictor":
168        """Fit one estimator per target and record the training envelope.
169
170        Parameters
171        ----------
172        table : pandas.DataFrame
173            Training table containing every feature and target column.
174
175        Returns
176        -------
177        SurrogatePredictor
178            self.
179
180        Raises
181        ------
182        KeyError
183            If a required column is absent.
184        ValueError
185            If the table contains NaN in any feature or target -- fitting through a
186            NaN silently drops rows and changes what the envelope means.
187        """
188        missing = [c for c in self.features + self.targets if c not in table.columns]
189        if missing:
190            raise KeyError(f"table is missing columns: {missing}")
191        subset = table[self.features + self.targets]
192        if subset.isna().to_numpy().any():
193            raise ValueError("training table contains NaN in a feature or target column")
194
195        X = subset[self.features].to_numpy(float)
196        for target in self.targets:
197            model = ESTIMATORS[self.estimator_name]()
198            model.fit(X, subset[target].to_numpy(float))
199            self.models_[target] = model
200        self.envelope_ = Envelope.from_table(table, self.features)
201        return self
202
203    def predict(self, X: pd.DataFrame) -> pd.DataFrame:
204        """Predict every target, flagging rows outside the training envelope.
205
206        Parameters
207        ----------
208        X : pandas.DataFrame
209            Query rows with the feature columns. Units follow
210            :data:`src.data.FEATURES`: litres, dimensionless, dimensionless,
211            degrees, radians.
212
213        Returns
214        -------
215        pandas.DataFrame
216            One column per target, in newtons, plus a boolean ``in_envelope`` and a
217            string ``out_of_range`` naming the offending features (empty when in
218            range). The flags are returned rather than only warned about, so a
219            caller can filter without re-deriving them.
220
221        Raises
222        ------
223        RuntimeError
224            If called before ``fit``.
225        KeyError
226            If a feature column is absent from ``X``.
227        ValueError
228            If ``X`` contains NaN, or if any row is out of envelope under
229            ``policy='refuse'``.
230
231        Warns
232        -----
233        UserWarning
234            Under ``policy='warn'``, once per call, naming how many rows fell
235            outside and which features were responsible.
236        """
237        if self.envelope_ is None:
238            raise RuntimeError("SurrogatePredictor.predict called before fit")
239        missing = [c for c in self.features if c not in X.columns]
240        if missing:
241            raise KeyError(f"query is missing feature columns: {missing}")
242
243        query = X[self.features]
244        if query.isna().to_numpy().any():
245            raise ValueError(
246                "query contains NaN. There is no defensible imputation for a board "
247                "dimension, so this refuses rather than guessing a hull."
248            )
249
250        flags = self.envelope_.check(query)
251        in_envelope = flags.all(axis=1)
252        offenders = flags.apply(
253            lambda row: ", ".join(sorted(flags.columns[~row])), axis=1
254        )
255
256        if not in_envelope.all():
257            names = sorted({f for row in offenders[~in_envelope] for f in row.split(", ") if f})
258            message = (
259                f"{int((~in_envelope).sum())} of {len(query)} queries fall outside the "
260                f"training envelope on: {', '.join(names)}. Predictions there are "
261                f"extrapolation, not interpolation."
262            )
263            if self.policy == "refuse":
264                raise ValueError(message)
265            if self.policy == "warn":
266                warnings.warn(message, UserWarning, stacklevel=2)
267
268        values = query.to_numpy(float)
269        out = pd.DataFrame(
270            {t: self.models_[t].predict(values) for t in self.targets}, index=X.index
271        )
272        out["in_envelope"] = in_envelope
273        out["out_of_range"] = offenders
274        return out

240        missing = [c for c in self.features if c not in X.columns]
241        if missing:
242            raise KeyError(f"query is missing feature columns: {missing}")
243
244        query = X[self.features]
245        if query.isna().to_numpy().any():
246            raise ValueError(

248                "dimension, so this refuses rather than guessing a hull."
249            )
250
251        flags = self.envelope_.check(query)
252        in_envelope = flags.all(axis=1)
253        offenders = flags.apply(
254            lambda row: ", ".join(sorted(flags.columns[~row])), axis=1
255        )
256
257        if not in_envelope.all():
258            names = sorted({f for row in offenders[~in_envelope] for f in row.split(", ") if f})

262                f"extrapolation, not interpolation."
263            )
