src.swd_model.identifiability_screen_live

Second identifiability screen: forces from ONE live-solver attitude, lift trimmed to the weight.

FEASIBILITY SCREEN ONLY. Nothing in this file is the project's forward model, and it must not be reused or described as one. It asks one question of the data already in hand: could an inverse fit recover a friction multiplier k from ~15 Hz along-path acceleration, using forces from a single board attitude whose lift SWD's live solver held at the weight?

It re-runs the first screen, because that one took its forces from the first trajectory model's load_polar(), which sums 7-12 scan positions per roll case (AI-USE.md section 5, E133). Both left the repository with Part A on 2026-10-28; the helpers this screen took from the first one (the mmc1 parser, sample times, noise bounds, metrics and palette) are copied here unchanged. Here the forces are one attitude's own: SWD's live solver, slope 0, drift 0, converged reads only. The model is a straight run at that one attitude::

D(V)      = k * friction(V) + planing(V) + rail(V)        (PCHIP in speed, never extrapolated)
m dV/dt   = m g sin(SLOPE_DEG) - D(V)

and only the along-path acceleration a_x is compared: lift is held at the weight, so a_z is zero, and a_y = V^2/R = g tan(phi) carries no friction information (Eq 64).

The attitude and the starting speed are chosen by fixed rules (steps 2 and 3 of the brief). Both are provisional, pending the author's review. Nothing here gives a pass/fail verdict.

 117def load_mmc1(path: Path = MMC1) -> pd.DataFrame:
 118    """Parse the paper's board sample (mmc1) as ``SOURCE.md`` describes it.
 119
 120    Parameters
 121    ----------
 122    path : pathlib.Path
 123        The archive as downloaded; it is read in place, never extracted.
 124
 125    Returns
 126    -------
 127    pandas.DataFrame
 128        148 rows in ascending time: ``t_s`` from 0, ``sg1..sg5``, ``ax_g, ay_g, az_g``
 129        (g, gravity included) and the gyroscope ``rx, ry, rz``.
 130
 131    Raises
 132    ------
 133    ValueError
 134        If any data row does not have the 12 fields.
 135    """
 136    with zipfile.ZipFile(path) as z:
 137        text = z.read("Board_Sample.txt").decode("ascii")
 138    # Every other line is a ';'-prefixed hex echo of the line above it - no new information.
 139    rows = [ln.split(";") for ln in text.splitlines() if ln.strip() and not ln.startswith(";")]
 140    bad = [i for i, r in enumerate(rows) if len(r) != len(MMC1_COLUMNS)]
 141    if bad:
 142        raise ValueError(f"mmc1 rows {bad[:5]} do not have {len(MMC1_COLUMNS)} fields")
 143    df = pd.DataFrame([[float(x) for x in r] for r in rows], columns=MMC1_COLUMNS)
 144    # The board counter (ms) runs backwards: reverse it and start the clock at zero.
 145    df = df.iloc[::-1].reset_index(drop=True)
 146    df.insert(0, "t_s", (df.t_ms - df.t_ms.iloc[0]) / 1000.0)
 147    return df.drop(columns="t_ms")

 169def quiet_window(mmc1: pd.DataFrame, length: int = QUIET_LENGTH) -> dict:
 170    """The quietest stretch of mmc1's accelerometer, as a noise upper bound (step 5).
 171
 172    Each window of ``length`` consecutive samples has a least-squares line in time removed
 173    from every axis; the window with the lowest summed residual variance wins. One window
 174    serves all three axes.
 175
 176    Parameters
 177    ----------
 178    mmc1 : pandas.DataFrame
 179        Output of :func:`load_mmc1`.
 180    length : int
 181        Window length in samples.
 182
 183    Returns
 184    -------
 185    dict
 186        ``start`` index, ``t0``/``t1`` in s, per-axis ``sigma`` (m/s^2, ddof = 2 for the two
 187        fitted line parameters) and per-axis lag-1 autocorrelation ``lag1`` of the residual.
 188
 189    Raises
 190    ------
 191    ValueError
 192        If ``length`` is not an integer from 3 to the number of samples.
 193    """
 194    # 3 or more leaves a residual after the two line parameters; more than len(mmc1) leaves no window at all
 195    if isinstance(length, (bool, np.bool_)) or not isinstance(length, (int, np.integer)) or not 3 <= length <= len(mmc1):
 196        raise ValueError(f"length must be an integer from 3 to {len(mmc1)}, got {length!r}")
 197    t = mmc1.t_s.to_numpy()
 198    acc = mmc1[["ax_g", "ay_g", "az_g"]].to_numpy() * G  # g, gravity included -> m/s^2
 199    best = None
 200    for i in range(len(t) - length + 1):
 201        tt, aa = t[i : i + length], acc[i : i + length]
 202        resid = np.column_stack([aa[:, c] - np.polyval(np.polyfit(tt, aa[:, c], 1), tt) for c in range(3)])
 203        score = float((resid**2).sum())
 204        if best is None or score < best[0]:
 205            best = (score, i, resid)
 206    _, i, resid = best
 207    return dict(
 208        start=i,
 209        t0=float(t[i]),
 210        t1=float(t[i + length - 1]),
 211        sigma=np.sqrt((resid**2).sum(axis=0) / (length - 2)),
 212        lag1=(resid[:-1] * resid[1:]).sum(axis=0) / (resid**2).sum(axis=0),
 213    )

 216def majority_sign_fraction(d: np.ndarray) -> float:
 217    """Fraction of samples sharing the curve's majority sign; exact zeros count as neither.
 218
 219    Parameters
 220    ----------
 221    d : numpy.ndarray
 222        One delta-a curve.
 223
 224    Returns
 225    -------
 226    float
 227        ``max(n_pos, n_neg) / n``.
 228
 229    Raises
 230    ------
 231    ValueError
 232        If ``d`` is empty or not finite.
 233    """
 234    d = np.asarray(d, dtype=float)
 235    if d.size == 0 or not np.all(np.isfinite(d)):
 236        raise ValueError("d must be a non-empty curve of finite values")
 237    return max(int((d > 0).sum()), int((d < 0).sum())) / d.size

 258def standard_error(kind: str, value: float, n: int) -> float:
 259    """Standard error of a Monte Carlo statistic over n draws, by the usual normal-theory approximations.
 260
 261    Printed beside each statistic (the author's choice, AI-USE.md section 4, 2026-10-28), because "settled < 5 %"
 262    is a stopping rule, not a statement of precision.
 263
 264    Parameters
 265    ----------
 266    kind : {'mean', 'sd', 'fraction', 'corr'}
 267        Which statistic: a mean (pass the draws' sd as value), a standard deviation (pass the sd), a fraction (pass
 268        p) or a correlation (pass r).
 269    value : float
 270        As above. NaN gives NaN.
 271    n : int
 272        Draws behind the statistic: the converged fits for k and V0, every fit for a fraction.
 273
 274    Returns
 275    -------
 276    float
 277        sd/sqrt(n) for a mean; sd/sqrt(2(n - 1)) for an sd; sqrt(p(1 - p)/n) for a fraction;
 278        (1 - r^2)/sqrt(n - 1) for a correlation. NaN when n is too small.
 279
 280    Raises
 281    ------
 282    ValueError
 283        If kind is not one of the four, n is a bool, or value is neither NaN nor inside its kind's range
 284        (>= 0 for a mean's sd and for an sd, [0, 1] for a fraction, [-1, 1] for a correlation).
 285    """
 286    ranges = {"mean": (0.0, np.inf), "sd": (0.0, np.inf), "fraction": (0.0, 1.0), "corr": (-1.0, 1.0)}
 287    if kind not in ranges:
 288        raise ValueError(f"kind must be 'mean', 'sd', 'fraction' or 'corr', got {kind!r}")
 289    if isinstance(n, (bool, np.bool_)):
 290        raise ValueError("n must be a count of draws (a bool is not)")
 291    lo, hi = ranges[kind]
 292    if not (np.isnan(value) or lo <= value <= hi):
 293        raise ValueError(f"a {kind} statistic of {value!r} is outside [{lo:g}, {hi:g}]")
 294    if kind == "mean":
 295        return float(value / np.sqrt(n)) if n > 0 else float("nan")
 296    if kind == "sd":
 297        return float(value / np.sqrt(2 * (n - 1))) if n > 1 else float("nan")
 298    if kind == "fraction":
 299        return float(np.sqrt(value * (1 - value) / n)) if n > 0 else float("nan")
 300    return float((1 - value**2) / np.sqrt(n - 1)) if n > 1 else float("nan")  # corr

 312def drop_inconsistent(df: pd.DataFrame, tol: float = DECOMP_TOL) -> tuple[pd.DataFrame, int]:
 313    """Keep rows whose friction + planing + rail drag adds up to the total drag (step 1).
 314
 315    Parameters
 316    ----------
 317    df : pandas.DataFrame
 318        Live-solver rows with ``drag_total_n``, ``friction_n``, ``fx_planing_n``, ``fx_rail_n``.
 319    tol : float
 320        Allowed mismatch as a fraction of ``|drag_total_n|``.
 321
 322    Returns
 323    -------
 324    kept : pandas.DataFrame
 325        The consistent rows.
 326    n_dropped : int
 327        How many rows failed.
 328    """
 329    gap = (df.drag_total_n - (df.friction_n + df.fx_planing_n + df.fx_rail_n)).abs()
 330    ok = gap <= tol * df.drag_total_n.abs()
 331    return df[ok], int((~ok).sum())

 353def continuous_range(speeds: np.ndarray) -> tuple[float, float]:
 354    """Longest run of consecutive 1 m/s grid speeds; among equal runs, the fastest.
 355
 356    Parameters
 357    ----------
 358    speeds : numpy.ndarray
 359        Converged speeds of one attitude, m/s.
 360
 361    Returns
 362    -------
 363    tuple of float
 364        ``(v_lo, v_hi)`` of that run, m/s.
 365    """
 366    v = np.sort(np.unique(speeds))
 367    if v.size == 0:
 368        raise ValueError("speeds is empty")
 369    best, start = (v[0], v[0]), v[0]
 370    for i in range(1, v.size + 1):
 371        if i == v.size or not np.isclose(v[i] - v[i - 1], 1.0):
 372            if v[i - 1] - start >= best[1] - best[0]:
 373                best = (float(start), float(v[i - 1]))
 374            if i < v.size:
 375                start = v[i]
 376    return best

 379def equilibria(drag, lo: float, hi: float, drive: float) -> list[float]:
 380    """Speeds in ``[lo, hi]`` where drag equals the slope's weight component.
 381
 382    Parameters
 383    ----------
 384    drag : callable
 385        ``drag(V) -> N``, vectorised.
 386    lo, hi : float
 387        Speed range, m/s.
 388    drive : float
 389        ``m g sin(slope)``, N.
 390
 391    Returns
 392    -------
 393    list of float
 394        Every crossing, ascending (a drag hump gives two).
 395    """
 396    v = np.linspace(lo, hi, 801)
 397    x = np.asarray(drag(v), dtype=float) - drive
 398    on_knot = [float(v[i]) for i in np.where(x == 0)[0]]
 399    between = [float(brentq(lambda s: float(drag(s)) - drive, v[i], v[i + 1]))
 400               for i in np.where(np.sign(x[:-1]) * np.sign(x[1:]) < 0)[0]]
 401    return sorted(on_knot + between)

 404@dataclass(frozen=True)
 405class Forces:
 406    """One attitude's drag components against speed, as shape-preserving (PCHIP) interpolants.
 407
 408    Attributes
 409    ----------
 410    pos_y, pos_x : float
 411        The attitude (SWD scan position).
 412    friction, planing, rail, total : scipy.interpolate.PchipInterpolator
 413        ``friction_n``, ``fx_planing_n``, ``fx_rail_n`` and SWD's own ``drag_total_n``, N. None
 414        extrapolates: outside the grid they return NaN.
 415    """
 416
 417    pos_y: float
 418    pos_x: float
 419    friction: PchipInterpolator
 420    planing: PchipInterpolator
 421    rail: PchipInterpolator
 422    total: PchipInterpolator
 423
 424    @classmethod
 425    def at(cls, df: pd.DataFrame, pos_y: float, pos_x: float, v_lo: float, v_hi: float) -> "Forces":
 426        """Build the interpolants for one attitude over its continuous converged range.
 427
 428        Parameters
 429        ----------
 430        df : pandas.DataFrame
 431            Output of :func:`load_forces`.
 432        pos_y, pos_x : float
 433            The attitude.
 434        v_lo, v_hi : float
 435            Its continuous converged speed range, m/s.
 436
 437        Returns
 438        -------
 439        Forces
 440        """
 441        g = df[(df.pos_y == pos_y) & (df.pos_x == pos_x) & df.speed_ms.between(v_lo, v_hi)].sort_values("speed_ms")
 442        v = g.speed_ms.to_numpy(dtype=float)
 443        p = {c: PchipInterpolator(v, g[c].to_numpy(dtype=float), extrapolate=False)
 444             for c in ("friction_n", "fx_planing_n", "fx_rail_n", "drag_total_n")}
 445        return cls(pos_y, pos_x, p["friction_n"], p["fx_planing_n"], p["fx_rail_n"], p["drag_total_n"])
 446
 447    @property
 448    def v_range(self) -> tuple[float, float]:
 449        """The converged speed range the interpolants cover, m/s."""
 450        return float(self.friction.x[0]), float(self.friction.x[-1])
 451
 452    def drag_poly(self, k: float) -> PPoly:
 453        """``k * friction + planing + rail`` as one piecewise cubic.
 454
 455        Parameters
 456        ----------
 457        k : float
 458            Friction multiplier.
 459
 460        Returns
 461        -------
 462        scipy.interpolate.PPoly
 463            The same polynomial as the sum of the three PCHIPs (they share breakpoints), evaluated
 464            once per call instead of three times; NaN outside the range.
 465        """
 466        return PPoly(k * self.friction.c + self.planing.c + self.rail.c, self.friction.x, extrapolate=False)

 469def integrate(drag, v0: float, t_end: float, v_range: tuple[float, float], m: float = MASS_KG,
 470              slope_deg: float = SLOPE_DEG, rtol: float = RTOL):
 471    """Integrate ``m dV/dt = m g sin(slope) - D(V)`` with RK45, stopping where V leaves the range.
 472
 473    Parameters
 474    ----------
 475    drag : callable
 476        ``drag(V) -> N`` (scalar in, scalar out).
 477    v0 : float
 478        Starting speed, m/s.
 479    t_end : float
 480        Run length, s.
 481    v_range : tuple of float
 482        ``(lo, hi)`` the forces are valid over, m/s.
 483    m : float
 484        Mass, kg.
 485    slope_deg : float
 486        Constant surface slope; its weight component is a separate term because the 0-degree
 487        forces do not contain it.
 488    rtol : float
 489        Relative tolerance.
 490
 491    Returns
 492    -------
 493    scipy.integrate.OdeResult
 494        With dense output; ``t[-1]`` is ``t_end``, or the time V reached a range edge.
 495    """
 496    lo, hi = v_range
 497    drive = m * G * np.sin(np.radians(slope_deg))
 498
 499    def rhs(t, y):
 500        """dV/dt. Trial stages of a step that crosses an edge can land just past it; the force there
 501        is held at its edge value, and the terminal events below cut the run at the edge."""
 502        return [(drive - float(drag(min(max(y[0], lo), hi)))) / m]
 503
 504    def below(t, y):
 505        """Zero where V reaches the bottom of the range."""
 506        return y[0] - lo
 507
 508    def above(t, y):
 509        """Zero where V reaches the top of the range."""
 510        return y[0] - hi
 511
 512    below.terminal = above.terminal = True
 513    return solve_ivp(rhs, (0.0, t_end), [v0], method="RK45", rtol=rtol, atol=ATOL,
 514                     events=[below, above], dense_output=True)

 517def run_accel(forces: Forces, k: float, v0: float, t_end: float, t: np.ndarray, rtol: float = RTOL):
 518    """Along-path acceleration at the sample times the run reaches, from the right-hand side.
 519
 520    Parameters
 521    ----------
 522    forces : Forces
 523        The attitude.
 524    k, v0 : float
 525        Friction multiplier and starting speed.
 526    t_end : float
 527        Run length, s.
 528    t : numpy.ndarray
 529        Sample times, s, ascending.
 530    rtol : float
 531        Relative tolerance for :func:`integrate`.
 532
 533    Returns
 534    -------
 535    a : numpy.ndarray
 536        ``(m g sin(slope) - D(V(t)))/m`` at the covered samples, m/s^2 (no differentiation of V).
 537    t_reached : float
 538        End of the run, s.
 539    sol : scipy.integrate.OdeResult
 540        The integration, for V(t).
 541    """
 542    lo, hi = forces.v_range
 543    d = forces.drag_poly(k)
 544    sol = integrate(d, v0, t_end, (lo, hi), rtol=rtol)
 545    t_reached = float(sol.t[-1])
 546    v = sol.sol(t[t <= t_reached + 1e-12])[0]
 547    # Only round-off may sit outside the range at the cut; anything more would be extrapolation.
 548    clipped = np.clip(v, lo, hi)
 549    if v.size and np.max(np.abs(v - clipped)) > EDGE_TOL:
 550        raise RuntimeError(f"V left the converged range by {np.max(np.abs(v - clipped)):.3g} m/s at a sample")
 551    return (WEIGHT_N * np.sin(np.radians(SLOPE_DEG)) - d(clipped)) / MASS_KG, t_reached, sol

 554def rank_attitudes(df: pd.DataFrame, top: int = 5) -> pd.DataFrame:
 555    """Rank attitudes by step 2's rule and describe the leaders.
 556
 557    Rule: widest continuous converged speed range, then the smallest ``|pos_y|``, then ``pos_x``
 558    nearest the median ``pos_x`` of the kept rows.
 559
 560    Parameters
 561    ----------
 562    df : pandas.DataFrame
 563        Output of :func:`load_forces`.
 564    top : int
 565        How many leaders get forces and equilibria attached.
 566
 567    Returns
 568    -------
 569    pandas.DataFrame
 570        Every attitude in rank order; the first ``top`` rows also carry the end forces and the
 571        equilibrium speeds.
 572    """
 573    med_x = float(df.pos_x.median())
 574    rows = []
 575    for (py, px), g in df.groupby(["pos_y", "pos_x"]):
 576        lo, hi = continuous_range(g.speed_ms.to_numpy(dtype=float))
 577        rows.append(dict(pos_y=py, pos_x=px, v_lo=lo, v_hi=hi, width=hi - lo))
 578    c = pd.DataFrame(rows)
 579    c = c.assign(_y=c.pos_y.abs(), _x=(c.pos_x - med_x).abs())
 580    c = c.sort_values(["width", "_y", "_x"], ascending=[False, True, True]).drop(columns=["_y", "_x"])
 581    c = c.reset_index(drop=True)
 582    drive = WEIGHT_N * np.sin(np.radians(SLOPE_DEG))
 583    extra = []
 584    for _, r in c.head(top).iterrows():
 585        if r.width < 1:  # one converged speed: nothing to interpolate
 586            extra.append({})
 587            continue
 588        f = Forces.at(df, r.pos_y, r.pos_x, r.v_lo, r.v_hi)
 589        e = {}
 590        for end, v in (("lo", r.v_lo), ("hi", r.v_hi)):
 591            e[f"friction_n_at_{end}"] = float(f.friction(v))
 592            e[f"fx_planing_n_at_{end}"] = float(f.planing(v))
 593            e[f"fx_rail_n_at_{end}"] = float(f.rail(v))
 594        e["v_eq_swd_total_k1"] = "; ".join(f"{x:.3f}" for x in equilibria(f.total, r.v_lo, r.v_hi, drive)) or "none in range"
 595        e["v_eq_model_k_planted"] = "; ".join(f"{x:.3f}" for x in equilibria(f.drag_poly(PLANTED), r.v_lo, r.v_hi, drive)) or "none in range"
 596        extra.append(e)
 597    return pd.concat([c, pd.DataFrame(extra)], axis=1)

 600def choose_v0(forces: Forces, t_end: float) -> tuple[float | None, pd.DataFrame]:
 601    """Step 3: the starting speed whose baseline run stays in range longest.
 602
 603    V0 runs over the range in 0.1 m/s steps, keeping only values whose +/- V0_SHIFT copies are in
 604    range too. Ties go to the largest change in V over the run, which is what separates friction
 605    from planing.
 606
 607    Parameters
 608    ----------
 609    forces : Forces
 610        The attitude.
 611    t_end : float
 612        Run length used for the choice (mmc1's span), s.
 613
 614    Returns
 615    -------
 616    v0 : float or None
 617        The choice, or None if no V0 qualifies.
 618    table : pandas.DataFrame
 619        Every grid value with ``qualifies``, ``t_in_range``, ``v_end`` and ``dv``.
 620    """
 621    lo, hi = forces.v_range
 622    d = forces.drag_poly(PLANTED)
 623    rows = []
 624    for tenth in range(int(round(lo * 10)), int(round(hi * 10)) + 1):
 625        v0 = tenth / 10
 626        ok = v0 * (1 - V0_SHIFT) >= lo - 1e-9 and v0 * (1 + V0_SHIFT) <= hi + 1e-9
 627        row = dict(v0=v0, qualifies=ok, t_in_range=np.nan, v_end=np.nan, dv=np.nan)
 628        if ok:
 629            sol = integrate(d, v0, t_end, (lo, hi))
 630            row.update(t_in_range=float(sol.t[-1]), v_end=float(sol.y[0, -1]), dv=abs(float(sol.y[0, -1]) - v0))
 631        rows.append(row)
 632    table = pd.DataFrame(rows)
 633    q = table[table.qualifies]
 634    if q.empty:
 635        return None, table
 636    best = q.sort_values(["t_in_range", "dv"], ascending=[False, False]).iloc[0]
 637    return float(best.v0), table

 640def select(df: pd.DataFrame, t_end: float) -> dict:
 641    """Attitude and starting speed by the rules of steps 2 and 3, falling back down the ranking.
 642
 643    Parameters
 644    ----------
 645    df : pandas.DataFrame
 646        Output of :func:`load_forces`.
 647    t_end : float
 648        mmc1's span, s.
 649
 650    Returns
 651    -------
 652    dict
 653        ``candidates`` (the ranking), ``forces`` and ``v0`` (None if nothing qualifies), ``rank``
 654        of the attitude used, and ``v0_table`` for it.
 655    """
 656    candidates = rank_attitudes(df)
 657    out = dict(candidates=candidates, forces=None, v0=None, rank=None, v0_table=None)
 658    for rank, r in candidates.iterrows():
 659        if r.width < 1:  # one converged speed: nothing to interpolate
 660            continue
 661        f = Forces.at(df, r.pos_y, r.pos_x, r.v_lo, r.v_hi)
 662        v0, table = choose_v0(f, t_end)
 663        if v0 is not None:
 664            return dict(out, forces=f, v0=v0, rank=int(rank), v0_table=table)
 665    return out

 668def residuals(params, forces: Forces, data: np.ndarray, sigma: float, t: np.ndarray, t_end: float,
 669              v0_fixed: float | None, hits: list[int]) -> np.ndarray:
 670    """Noise-weighted misfit of a_x; samples a trial run never reached get a fixed penalty.
 671
 672    Parameters
 673    ----------
 674    params : numpy.ndarray
 675        ``[k]`` when ``v0_fixed`` is given (set a), else ``[k, v0]`` (set b).
 676    forces : Forces
 677        The attitude.
 678    data : numpy.ndarray
 679        a_x being fitted, at ``t``.
 680    sigma : float
 681        Noise standard deviation, m/s^2.
 682    t : numpy.ndarray
 683        Sample times, s.
 684    t_end : float
 685        Run length, s.
 686    v0_fixed : float or None
 687        Starting speed held fixed, or None to fit it.
 688    hits : list of int
 689        One-element counter, incremented when a trial leaves the range early.
 690
 691    Returns
 692    -------
 693    numpy.ndarray
 694        One residual per sample.
 695    """
 696    k, v0 = (params[0], v0_fixed) if v0_fixed is not None else (params[0], params[1])
 697    a, _, _ = run_accel(forces, k, v0, t_end, t)
 698    r = np.full(t.size, GUARD_RESIDUAL)
 699    r[: a.size] = (a - data[: a.size]) / sigma
 700    if a.size < t.size:
 701        hits[0] += 1
 702    return r

 705def fit(forces: Forces, data: np.ndarray, sigma: float, t: np.ndarray, t_end: float, v0_true: float,
 706        joint: bool) -> dict:
 707    """Fit k (set a) or k and V0 (set b) from deliberately shifted starts.
 708
 709    Parameters
 710    ----------
 711    forces : Forces
 712        The attitude.
 713    data : numpy.ndarray
 714        a_x at ``t``, m/s^2.
 715    sigma : float
 716        Noise standard deviation, m/s^2.
 717    t : numpy.ndarray
 718        Sample times, s.
 719    t_end : float
 720        Run length, s.
 721    v0_true : float
 722        True starting speed: fixed in set a, perturbed for the start in set b.
 723    joint : bool
 724        True for set b.
 725
 726    Returns
 727    -------
 728    dict
 729        ``k_fit``, ``v0_fit`` (NaN for set a), ``converged``, ``at_bound``, ``guard_hits``, ``nfev``.
 730    """
 731    lo, hi = forces.v_range
 732    hits = [0]
 733    if joint:
 734        x0, bounds = [PLANTED * (1 + FRICTION_SHIFT), v0_true * (1 + V0_SHIFT)], ([0.0, lo], [np.inf, hi])
 735    else:
 736        x0, bounds = [PLANTED * (1 + FRICTION_SHIFT)], ([0.0], [np.inf])
 737    res = least_squares(residuals, x0, bounds=bounds, diff_step=DIFF_STEP,
 738                        args=(forces, data, sigma, t, t_end, None if joint else v0_true, hits))
 739    k = float(res.x[0])
 740    v0 = float(res.x[1]) if joint else v0_true
 741    # A fit is only usable if its own run reaches every sample it was fitted to.
 742    covers = run_accel(forces, k, v0, t_end, t)[0].size == t.size
 743    return dict(k_fit=k, v0_fit=v0 if joint else np.nan, converged=bool(res.success) and covers,
 744                at_bound=bool(np.any(res.active_mask != 0)), guard_hits=hits[0], nfev=int(res.nfev))

 747class NoiseDraws:
 748    """Standard-normal draws, made one at a time in a fixed order so draw i never changes.
 749
 750    Parameters
 751    ----------
 752    seed : int
 753        Seed of the generator.
 754    n : int
 755        Samples per draw.
 756    """
 757
 758    def __init__(self, seed: int, n: int):
 759        """Start the generator; no draw is made until one is asked for."""
 760        self._rng, self._n, self._draws = np.random.default_rng(seed), n, []
 761
 762    def __getitem__(self, i: int) -> np.ndarray:
 763        """Draw ``i``, generating any earlier ones first."""
 764        while len(self._draws) <= i:
 765            self._draws.append(self._rng.standard_normal(self._n))
 766        return self._draws[i]

 769def monte_carlo(forces: Forces, clean: np.ndarray, noise: NoiseDraws, sigma: float, t: np.ndarray, t_end: float,
 770                v0_true: float, joint: bool, allowance_s: float, per_fit_est: float) -> tuple[list[dict], dict]:
 771    """Fit noisy copies of the baseline, doubling N until the sd of k settles or the time runs out.
 772
 773    Parameters
 774    ----------
 775    forces : Forces
 776        The attitude.
 777    clean : numpy.ndarray
 778        Baseline a_x at ``t``.
 779    noise : NoiseDraws
 780        Shared standard-normal draws; draw i is scaled by ``sigma``.
 781    sigma : float
 782        Noise standard deviation, m/s^2.
 783    t : numpy.ndarray
 784        Sample times, s.
 785    t_end : float
 786        Run length, s.
 787    v0_true : float
 788        True starting speed, m/s.
 789    joint : bool
 790        True for set b.
 791    allowance_s : float
 792        Wall time this combination may use, s.
 793    per_fit_est : float
 794        Timed seconds per fit, used until real fits replace it.
 795
 796    Returns
 797    -------
 798    fits : list of dict
 799        Every fit, in draw order.
 800    stop : dict
 801        ``n`` and ``n2`` of the last comparison with their ``sd_n`` and ``sd_n2``, ``settled``,
 802        and ``capped`` when the time cap ended the doubling.
 803    """
 804    fits: list[dict] = []
 805    start = time.perf_counter()
 806
 807    def per_fit() -> float:
 808        """Seconds per fit so far (the timing estimate before the first fit)."""
 809        return (time.perf_counter() - start) / len(fits) if fits else per_fit_est
 810
 811    def sd_k(n: int) -> float:
 812        """sd (ddof 1) of converged fitted k among the first n draws."""
 813        k = [f["k_fit"] for f in fits[:n] if f["converged"]]
 814        return float(np.std(k, ddof=1)) if len(k) > 1 else float("nan")
 815
 816    def extend(n: int) -> None:
 817        """Fit draws until there are n fits."""
 818        while len(fits) < n:
 819            fits.append(fit(forces, clean + noise[len(fits)] * sigma, sigma, t, t_end, v0_true, joint))
 820
 821    stop = dict(n=np.nan, n2=np.nan, sd_n=np.nan, sd_n2=np.nan, settled=False, capped=False)
 822    first = min(N0, max(2, int(allowance_s / per_fit_est)))
 823    extend(first)
 824    if first < N0:
 825        return fits, dict(stop, n=first, capped=True)
 826    n = N0
 827    while True:
 828        if time.perf_counter() - start + n * per_fit() > allowance_s:
 829            return fits, dict(stop, capped=True)
 830        extend(2 * n)
 831        sd_n, sd_n2 = sd_k(n), sd_k(2 * n)
 832        stop.update(n=n, n2=2 * n, sd_n=sd_n, sd_n2=sd_n2)
 833        if sd_n > 0 and abs(sd_n2 - sd_n) / sd_n < STD_REL_TOL:
 834            return fits, dict(stop, settled=True)
 835        n *= 2
 836

 838def mc_stats(f: pd.DataFrame, joint: bool) -> dict:
 839    """Summary of one set of fits, with the conventions stated in READINGS.
 840
 841    Parameters
 842    ----------
 843    f : pandas.DataFrame
 844        Fits with ``k_fit``, ``v0_fit``, ``converged`` (and ``at_bound`` where known).
 845    joint : bool
 846        True for set b (adds the V0 statistics).
 847
 848    Returns
 849    -------
 850    dict
 851        N, mean and sd of k, sd / (FRICTION_SHIFT x PLANTED), within-band fraction, converged
 852        and at-bound fractions, and for set b the V0 mean, sd and corr(k, V0). Each statistic is
 853        followed by its standard error, "SE ..." (:func:`standard_error`).
 854    """
 855    ok = f[f.converged]
 856    band = FRICTION_SHIFT * PLANTED
 857    sd = ok.k_fit.std(ddof=1)
 858    within = (((f.k_fit - PLANTED).abs() <= band) & f.converged).mean() if len(f) else np.nan
 859    at_bound = f.at_bound.mean() if "at_bound" in f else np.nan
 860    sd_v0 = ok.v0_fit.std(ddof=1) if joint else np.nan
 861    corr = correlation(ok.k_fit.to_numpy(), ok.v0_fit.to_numpy()) if joint else np.nan
 862    se = standard_error
 863    # Each statistic with its standard error beside it (the author's choice, AI-USE.md section 4, 2026-10-28):
 864    # "settled" is a stopping rule, not a precision
 865    return {
 866        "N": len(f), "mean k": ok.k_fit.mean(), "SE mean k": se("mean", sd, len(ok)),
 867        "sd k": sd, "SE sd k": se("sd", sd, len(ok)),
 868        "sd k / (shift x PLANTED)": sd / band, "SE sd k / (shift x PLANTED)": se("sd", sd, len(ok)) / band,
 869        "within ±band": within, "SE within ±band": se("fraction", within, len(f)),
 870        "converged": f.converged.mean(), "SE converged": se("fraction", f.converged.mean(), len(f)),
 871        "at bound": at_bound, "SE at bound": se("fraction", at_bound, len(f)),
 872        "mean V0": ok.v0_fit.mean() if joint else np.nan, "SE mean V0": se("mean", sd_v0, len(ok)),
 873        "sd V0": sd_v0, "SE sd V0": se("sd", sd_v0, len(ok)),
 874        "corr(k, V0)": corr, "SE corr(k, V0)": se("corr", corr, len(ok)),
 875    }
